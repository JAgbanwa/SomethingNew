# Summary of changes for run 94b5cf72-01f3-422f-bb3c-aca64a47b623
**Answer.** Reading the square root as the principal (nonnegative) real root, the equation

`36n³ − 19 = −2d·x²·(−(x+6n) + √((x+6n)² + (36n³−19)/x))`

is *equivalent* (theorem `DEquation.sat_iff` in `RequestProject/Main.lean`) to two purely rational conditions:

* `36n³ − 19 = 4d²x³ + 4dx³ + 24dnx²` (the equation with the radical cleared), and
* `2dx + x + 6n ≤ 0` (which branch of the root is taken).

From this I derived a complete criterion (`DEquation.exists_d_iff`): integers `n`, `x ≠ 0` admit some rational `d` **iff** `x²(x+6n)² + x(36n³−19)` is a perfect square, and then `d` is uniquely determined by `(n,x)` (`DEquation.sat_unique`), namely `d = (e − (x+6n))/(2x)` with `e = −√(x²(x+6n)² + x(36n³−19))/|x|`. For fixed `d` the first condition is a cubic Thue-type equation `36n³ − 24dnx² − 4d(d+1)x³ = 19`, so each admissible `d` has only finitely many integer solutions.
