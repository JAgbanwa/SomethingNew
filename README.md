# SomethingNew

The current 390 computation is a **gap search** with Booker–Sutherland's
method (`d = |x+y|`, cube roots of `k` mod `d`), aimed at the region their 2020
k = 390 search left out: `d > 10^19/54`, `|z| <= 64 d`. It has a project
ceiling of **1,800 core-hours**; **200 additional hours are reserved for
other projects**.

Start with the [gap search guide](390%20/Scripts%20for%20large-scale%20computations%20/GAP_SEARCH.md)
for the method, the expected-yield estimate, validation and commands, and the
[390 folder README](390%20/Scripts%20for%20large-scale%20computations%20/README.md)
for the container. The earlier rational-d (d-first) search remains there as a
historical engine.
